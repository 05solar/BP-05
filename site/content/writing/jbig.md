**수행 정보** — 2026 오픈소스 SW 해커톤 · **2인 팀** · 🏆 **대상**(총장상, 전북대학교 SW중심사업단) · RAG · PostgreSQL + pgvector · 로컬 OCR · LLM · Docker Compose

## 문제

언어·제도 장벽 때문에 외국인 근로자·유학생은 임금체불, 계약, 체류 연장 같은 문제에서 정확한 정보를 찾기 어렵다. 일반 챗봇으로 대응하면 근거 없는 답변(환각)이 오히려 위험을 키운다. 핵심 요구는 "**아는 것만, 근거와 함께** 답하는 상담"이었다.

## 접근

- **승인 문서 한정 하이브리드 검색 RAG** — 키워드 검색과 pgvector 벡터 검색을 결합하되, 검색 대상을 관리자가 승인한 공식 문서(법령·고용노동부·출입국)로 한정했다. 근거가 부족하면 추측하는 대신 공식기관 확인을 유도한다.
- **무중단 폴백** — LLM 호출이 실패하면 규칙 기반 답변으로 전환해 서비스가 끊기지 않게 했다.
- **출처의 가시화** — 답변에 사용된 자료를 신뢰도·관련도·권위 점수와 함께 출처 카드로 노출해, 사용자가 답의 근거를 직접 확인할 수 있게 했다.
- **문서 검토 기능** — 근로계약서·임금명세서를 업로드하면 로컬 OCR로 읽어 위약금 조항, 최저임금 미달, 가산수당 누락 같은 위험 요소를 규칙 기반으로 스크리닝한다.
- **다국어 절차 가이드** — 체류·노동 관련 절차 가이드 13종을 한국어·영어·베트남어 3개 언어로 제공하고, 좌표→지역 해석을 외부 API 없이 서버에서 결정적으로 처리해 관할 기관을 매칭했다.

## 배운 점

RAG에서 품질을 결정하는 것은 모델이 아니라 **검색 대상의 통제**라는 점을 배웠다. "무엇이든 답하는" 챗봇보다 "승인된 문서 안에서만 답하는" 챗봇이 이 도메인에서는 더 신뢰받는다. 또한 LLM 의존 서비스에서 폴백 경로를 처음부터 설계하는 것이 가용성에 결정적이라는 것도 확인했다.
